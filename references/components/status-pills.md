Status pills is a compact, read-only label that communicates the current state of a resource or operation. It is a beta proposal from the FlowX DS Gap Audit of September 4, 2026 (adoption item #1), last updated 2026-09-07, not a shipped product API: colors are FlowX palette tokens and typography matches existing soft tags, while sizes, paired foreground colors, icon scale, and the dark treatment are a proposed consolidation rather than a Figma extraction, and no Figma link or extracted node data exists. It accepts the following props: Label (string, required, an explicit state in sentence case of preferably one to three words, with a meaningful fallback for unknown values), Tone ("Neutral", "Info", "Success", "Warning", or "Danger", defaulting to "Neutral", chosen from the state's meaning in its domain and never inferred from the label alone), Size ("Small" or "Medium", defaulting to "Small", with Small for rows and dense lists and Medium for resource headers and summaries), Icon (boolean, default false, an optional leading semantic icon that supplements the label and shares its foreground color), and Surface ("Light" or "Dark", defaulting to "Light", which selects the foreground/background pair for the surface behind the pill). Its five states are the tones themselves, Neutral, Info, Success, Warning, and Danger; hover, pressed, selected, focused, and disabled interaction states do not exist by design, so there are no focus ring, hover, pressed, or disabled colors, although "Disabled" may still be a resource's visible label. It comes in two sizes: Small and Medium. Its anatomy consists of a Container that is a content-sized, borderless pill with a soft semantic fill, 999px corner radius, no border or shadow, laid out as inline-flex with items centered and a 4px gap between icon and label, whose width follows content and whose minimum height grows when a translated label wraps; an optional LeadingIcon at 12x12 in both sizes, matching the label's font size, using the same foreground color, hidden by default and decorative to assistive technology; and a required Label in Open Sans 12px / 16px, weight 600 at both sizes, that keeps the complete status visible including words such as "not" or "failed". Small has a 20px minimum height with 8px horizontal and 2px vertical padding; Medium has a 24px minimum height with 12px horizontal and 4px vertical padding; both use a 12px icon, a 4px gap, and a 999px radius, and the heights are minimums (2 + 16 + 2 = 20 and 4 + 16 + 4 = 24 for a single line) rather than fixed values. The container also sets max-width 100%, a default cursor, middle vertical alignment, and border-box sizing, and the label sets min-width 0 with overflow-wrap anywhere. The documentation preview draws its icons from Phosphor at the "bold" weight, CircleDashed for Neutral, Clock for Info, CheckCircle for Success, Warning for Warning, and XCircle for Danger, though the spec only requires a check, warning, error, or progress symbol and does not define icon stroke weight. The rendered component applies the font through the site variable var(--font-flowx) where the spec names Open Sans, and sets display inline-flex where the spec helper would emit flex.

Text and icon share the foreground token and the container uses the background token, and each light or dark pair must be used together. On a light surface, Neutral is #475263 (--flowx-neutrals-700) on #e3e8ed (--flowx-neutrals-100) at 6.41:1, Info is #004c99 (--flowx-blue-700) on #e6f0fb (--flowx-blue-50) at 7.31:1, Success is #005b44 (--flowx-green-700) on #e6f2ef (--flowx-green-50) at 7.10:1, Warning is #8b3b0f (--flowx-orange-800) on #fff0e8 (--flowx-orange-50) at 6.92:1, and Danger is #a31800 (--flowx-red-700) on #fde9e6 (--flowx-red-50) at 6.69:1. On a dark surface, Neutral is #cbd1db (--flowx-neutrals-200) on #2a313a (--flowx-neutrals-800) at 8.56:1, Info is #8abbed (--flowx-blue-200) on #002d5b (--flowx-blue-900) at 6.82:1, Success is #8ac5b6 (--flowx-green-200) on #003628 (--flowx-green-900) at 6.89:1, Warning is #febb97 (--flowx-orange-200) on #6a2d0c (--flowx-orange-900) at 6.41:1, and Danger is #f4998a (--flowx-red-200) on #610e00 (--flowx-red-900) at 6.22:1. Contrast values are computed with the site's own contrastRatio() formula from the resolved hex pairs, and all ten exceed 4.5:1 at 12px. In the documentation, light examples sit on --flowx-grays-50 (#ffffff) or --flowx-neutrals-50 (#f7f8f9) and dark examples on --flowx-neutrals-900 (#1d232c). No border or stroke is defined on either surface, so there is no dark-surface border token, and no spacing token is cited for the gap or padding values, which the sources give as raw pixels only. The tones carry fixed meanings: Neutral is a passive state with no immediate action (draft, queued, inactive, unknown; default label "Draft"), Info means work is progressing or a transition is underway (running, importing, in progress; default label "In progress"), Success means an operation succeeded or a resource is ready (completed, passed, active, ready; default label "Completed"), Warning means attention or a decision is needed to continue (action required, blocked, deprecated; default label "Action required"), and Danger means an operation failed or access was denied (failed, error, denied; default label "Failed").

Usage guidance says to use the same meaning in every view (a migration in progress keeps its blue Info tone in the table and in the resource header; size can change with density but meaning cannot), to separate ongoing work from attention (Info for normal processing, Warning reserved for a condition that needs intervention such as an import waiting at an approval gate), to keep context in the label ("Active" can be an enabled account, which is Success, or a token still executing, which is Info, so map the domain state first and never use a universal keyword-to-color lookup), to let a pill describe while an action sits beside it (read-only with a default cursor, with a separate button for Retry, Review, or Enable), to keep passive states visually quiet (Neutral for drafts, queued work, or intentionally inactive resources, while blocked access may need Danger), to always keep the words (never replace a status with a colored dot, a checkmark alone, or a tooltip, and use a full label for unknown states while preserving the source value in the details), and to choose the pair for the surface (dark-surface colors are part of this proposal since the product has no shared dark pill contract yet). Do not give build versions, branch names, environments, counters, or removable filter chips a success or warning meaning just because they have a pill-shaped container. For accessibility the pill is static text in a span, Tab skips it and any adjacent action needs its own focusable button or link, the decorative icon carries aria-hidden="true", a meaningful change is announced once through a dedicated role="status" region with aria-live="polite" rather than on every pill in a table, long labels stay complete and the pill grows vertically instead of truncating, and a static progress icon is sufficient with reduced-motion preferences honored if an implementation animates it. Adoption notes record that current tags mix solid fills, soft fills, and six corner treatments while this proposal standardizes status on a soft, full-radius pill; that migration progress is Warning in tables and Info in headers and process Started and active tokens also use Warning, so normal ongoing work should move to Info; that the shared status wrapper uses Neutral for Info while soft tags use Blue and its 500-level foregrounds differ from this proposal's darker text; that runtime content uses different green shades and an 8px radius and its red Clearing state needs a domain review; that runtime users map Disabled to Danger and access restrictions must keep their meaning; and that documented drift is not an approved exception. The spec defines no decisionLog, considerations, or knownExceptions, and no numeric maximum label length. Related components are button and values-table.
